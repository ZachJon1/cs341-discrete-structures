# Lecture PDFs

Upload publicly shareable lecture notes here (e.g., `lecture-21.pdf`).

Once uploaded, set the corresponding `notes` value in `data/lectures.json` to `notes/lecture-21.pdf`. You can also link externally hosted notes using a full `https://` URL. The website only displays buttons for resources with a URL/path.

**Do not upload material you are not authorized to publish.**
